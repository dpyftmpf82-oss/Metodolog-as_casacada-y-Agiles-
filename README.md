# Metodolog-as_casacada-y-Agiles-
Proyecto escolar sobre metodologías de desarrollo 
Este proyecto tiene como objetivo investigar y comparar las metodologías en cascada y ágiles identicando sus características, ventajas y desventajas 
Metodología en cascada es un modelo de desarrollo que sigue pasos ordenados uno después de otro
Metodología Ágiles enfoque flexible e interactivo que agrega valor en ciclos
cuadro comparativo entre ambas metodologías
